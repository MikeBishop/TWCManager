# Task 20: Fleet Telemetry field mapping and doc match what presence consumes
Requested 2026-10-20 by the "Vehicle detection without hardware control" session on Mike's behalf. Findings checked against adb6a215.

1. docs/modules/Vehicle_FleetTelemetryMQTT.md example `fields` omits ChargeCurrentRequest, ChargeAmps, ChargerPhases, ChargerVoltage, which the module already consumes in `events`. Without them a Fleet-Telemetry-only car on a mobile connector has no amps/voltage/phases (VehicleEndpoint.maxPower falls to the wiring default; actualCurrent never arrives, so Presence.asleep() loses "current drawn" as life). Add them.
2. Code gap: Presence._awayCharger uses fastChargerPresent, fastChargerType, connChargeCable, chargerPower, chargeCurrentRequestMax. TeslaAPI maps all five (~TeslaAPI.py:1856), TeslaMateVehicle the last two, FleetTelemetryMQTT none. Fleet Telemetry publishes FastChargerPresent, FastChargerType, ChargingCableType, ACChargingPower, ChargeCurrentRequestMax. Confirm exact names and value shapes against Tesla's Fleet Telemetry available-data list (enum values may carry a type prefix as DetailedChargeState does, stripped with a[19:]; derive the right strip per field). Add them to `events` (~6 lines) and to the doc. Test: a telemetry-only car reporting a fast charger inside the radius is not plug evidence.
3. Doc fallback paragraph: rewrite. On phase5 a feed's liveness is its MQTT connection plus health (Telemetry.feedLiveAt; Vehicle._ageOf gives age 0 while connected), so a sleeping car never triggers fallback; fallback only when the broker or telemetry server is down.
4. Doc: state the `connectivity` record is required — it is the only online/offline signal (CONNECTED/DISCONNECTED → state online/offline; Gear and DetailedChargeState only refine it). Put it next to the note on `retained`.
Doc shape for fields: group by purpose — Presence: Location, Gear, DetailedChargeState, connectivity. Charging: ChargeAmps, ChargerVoltage, ChargerPhases, ChargeCurrentRequest. Home-charger narrowing: the five above. Display: BatteryLevel, ChargeLimitSoc, TimeToFullCharge, VehicleName. 60 s intervals stay.
Out of scope: a sleep-driven "watch" for cars with no live feed; recording body-controller-state closureStatuses.chargePort.
